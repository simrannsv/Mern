## Week 7 — Capstone Project: Blog App

Full stack MERN blog application with authentication and deployment.

| Folder | Description |
|--------|-------------|
| blog-app-backend | Express + MongoDB REST API |
| blog-app-frontend | React.js frontend |

### Features
- JWT authentication — register and login
- Create, read, update, delete blog posts
- Protected routes for authenticated users
- Cross-domain cookie support for production
- Deployed on Vercel and Render

## How to Run

### JavaScript files (Week 1 & 2)
```bash
node filename.js
```

### Backend projects (Week 3 & 7)
```bash
npm install
node server.js
```

### React projects (Week 5, 6 & 7)
```bash
npm install
npm run dev
```
