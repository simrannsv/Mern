# Week 2 — Advanced JavaScript Concepts

Advanced concepts including classes, modules, array methods, and backend fundamentals.

---

## Folders

### Arrays-advanced
Advanced array methods and transformations
- map, filter, reduce, find, some, every
- Real-world backend-style data transformations

### Backend-1
Introduction to backend concepts using Node.js
- HTTP server without Express
- Routing basics
- Handling JSON requests

### Timer-functions
Asynchronous JavaScript concepts
- setTimeout, setInterval, clearTimeout
- Callbacks and timing functions

### class
Object-Oriented Programming in JavaScript
- Class declarations
- Constructor, methods
- Inheritance and extends

### modules
Modular JavaScript
- import/export syntax
- Splitting code into reusable modules
- Folder structure for backend logic

### shallow&DeepCopy
Understanding JavaScript object copying
- Shallow copy vs deep copy
- Spread operator for copying
- structuredClone and JSON methods

### spread&restparam
Spread and Rest operators
- Spread in arrays and objects
- Rest parameters in functions
- Destructuring with spread

---

## Concepts Covered
- Advanced array methods
- Classes and OOP
- Modules and imports
- Shallow vs deep copy
- Spread and rest operators
- Timer functions and async basics
- Node.js backend introduction
