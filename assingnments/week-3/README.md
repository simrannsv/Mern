# Week 3 — MongoDB & Express API

Building REST APIs with Express.js connected to MongoDB, covering CRUD operations and database commands.

---

## Files

### server.js
Express server initialization with MongoDB connection
- MongoDB connection setup using Mongoose
- Express app configuration
- Route registration

### userApi.js
User management REST API
- Create user
- Read all users
- Update user
- Delete user

### productApi.js
Product management REST API
- Create product
- Read all products
- Update product
- Delete product

### mongodb.txt
MongoDB shell commands reference for employee management
- insert, find, update, delete commands
- Query filters and operators

---

## Concepts Covered
- Express.js REST API setup
- MongoDB connection with Mongoose
- Schema and model creation
- CRUD operations with MongoDB
- API testing with REST client

---

## How to Run

1. Install dependencies
```bash
npm install
```

2. Add your MongoDB URL in .env
