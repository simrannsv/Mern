# Week 6 — React Full Stack & MERN Integration

Full stack React projects connecting frontend to Express backend, covering forms, tables, and employee management.

---

## Projects

### form-data-into-table
React form that dynamically updates a table with submitted data

- User creation form with input fields
- Form data displayed in a table below
- State management with useState
- Dynamic table updates without page reload

### employee-app/frontend
Full stack Employee Management App frontend connected to Express backend

- View all employees
- Create new employee
- Update employee details
- Delete employee
- API integration with backend using fetch/axios

---

## Concepts Covered
- Controlled form components
- useState and useEffect hooks
- Making API requests from React
- Loading and error states
- CRUD operations from frontend
- Connecting React to Express backend
- Client side routing with React Router

---

## How to Run

### form-data-into-table
```bash
cd form-data-into-table
npm install
npm run dev
```

### employee-app
```bash
cd employee-app/frontend
npm install
npm run dev
```
Make sure the backend server is running before starting the frontend.
