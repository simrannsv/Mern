## react-1
Introduction to React — components, props, and state

### Files
- **main.jsx** — React app entry point
- **App.jsx** — Root component
- **App.css** — App styles
- **index.css** — Global styles
- **Counter.jsx** — Counter component using useState
- **Product.jsx** — Product display component using props

### Concepts Covered
- Functional components
- Props and destructuring
- useState hook
- Event handling
- Rendering lists with map

### How to Run
```bash
cd react-1
npm install
npm run dev
```
